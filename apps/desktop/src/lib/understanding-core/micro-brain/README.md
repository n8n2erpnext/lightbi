# Micro Semantic Brain V1

Status: MB-0/MB-1/MB-2 foundation; no production semantic wiring.

This module is a local deterministic recall/inference helper for `understanding-core`. It broadens semantic candidate discovery from typed business knowledge without replacing the canonical registry, resolver, domain support manifest, grain/readiness gates, M1/M2/M3, metric preflight, or runtime authority.

## Authority boundary

```text
Micro Brain retrieval -> candidate hypothesis / relation clue
Semantic registry     -> canonical signal identity
Semantic resolver     -> evidence-bound resolution / abstention
Domain support        -> official supported capability truth
Grain + metric gates  -> calculation and execution authority
```

`denseSimilarity`, BM25 score, and RRF rank are retrieval provenance only. They are never semantic confidence.

## Source knowledge

`knowledge/*.foundation.v1.json` is generated by `scripts/micro-brain/synthesize-foundation-v1.mjs` from curated reusable knowledge. The current seed is a GPT-5.6 Sol model-synthesized business foundation aligned with existing LightBI contracts. It deliberately includes negative/confusion knowledge and unsupported-domain concepts.

The `foundational_seed_target_35_percent` maturity label is an engineering coverage target, not a claim that 35% of all business knowledge can be objectively measured.

Generated knowledge and compiled artifacts must not contain fixture identities, expected answers, or customer-specific truth.
## Rebuild

From repository root:

```bash
pnpm micro-brain:build
```

The build regenerates source cards and the immutable compiled hybrid index. Identical source/config must reproduce the same byte SHA-256.

## Current V1 retrieval

- sparse BM25 over semantic units;
- TF-IDF / LSA dense vectors compiled with deterministic SVD sign canonicalization;
- Reciprocal Rank Fusion by parent concept;
- positive and negative retrieval units preserved separately;
- explicit canonical bridges only when the registry signal exists;
- open concepts remain open concepts.

## Phase rule

MB-0 through MB-2 are additive only. MB-3 may observe physical columns in shadow mode but must not change Phase 3A candidates or resolver output. MB-4 is the earliest phase allowed to propose a versioned evidence bridge, and even then vector retrieval alone cannot create `probable` or `confirmed` semantics.
