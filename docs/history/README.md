# Historical Documentation

This tree contains repository-root Markdown that was reorganized on 2026-08-29 without rewriting its historical meaning.

Use [`LEGACY_ROOT_INDEX.md`](./LEGACY_ROOT_INDEX.md) when an older handoff, prompt, commit message, or conversation mentions the former root filename.

Categories:

- `agent/` — handoffs, implementation plans, walkthroughs, and agent contracts;
- `checkpoints/` — safepoints/checkpoints;
- `verifications/` — verification/proof records;
- `audits/` — historical audits;
- `reports/` — reports/probes/stress tests;
- `sample-evidence/` — historical sample-data acceptance/evidence;
- `foundation-notes/` — infrastructure/domain/scope notes;
- `project-memory/` — old project memory/changelog/transition memos;
- `misc/` — historical material not yet worth a narrower class.

Historical documents can be valuable evidence without being current architecture authority. Use the Project Book source-precedence rules before treating one as current truth.
