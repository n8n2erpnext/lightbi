# Phase 7R4 - MVP Candidate Packaging And Release Closure

## Decision

The exact Phase 7R3.8 implementation was packaged as candidate commit
`bbb9b997f7af4bb731a5b3197868bd19f49abfcd` with tree
`b3846735e847d1f76ca4db9536f4e7020205848e`. The candidate does not pass the
clean-checkout release gate because corpus 1.2.0 still requires 13 ignored
operational sample files that are absent from the repository.

No missing file was copied into the detached worktree, no external path was
read, and no source, test, corpus, policy, generator, oracle, dependency or
threshold changed after candidate creation. The failure is therefore a
truthful repository-input closure result, not a semantic correction phase.

## Data Boundary

Only the six approved Sales, Logistics and Accounting May/June fixture anchors
were repository-controlled under `sample-corpus/anchors/1.3.0/`. Their bytes
match the frozen hashes. Header, representative-value and pattern scans found
no secret, credential, email address or prohibited personal-name field;
numeric phone-pattern matches were reviewed as identifiers or timestamps.

The complete `sample data/` directory was not committed. This correctly
preserved the privacy boundary, but exposed an earlier contract mismatch:
corpus 1.2.0 marks 19 unique source paths as required while only the six
approved anchors are available in the candidate. The other 13 paths include
BHX, Superstore, inventory, World Bank, World Cup, bank, vehicle and ranking
workbooks. They were neither committed nor consumed during clean verification.

## Failed Gates

The clean corpus 1.2 evaluation could not start its complete governed
population because 13 required source files were missing. The complete
understanding-core matrix therefore finished with 55/73 files and 289/321
tests passing. Its 32 failures were direct missing-file failures or downstream
population assertions caused by those missing inputs.

The full desktop suite was run exactly once. It finished with 142/166 files
passing and 1,053/1,135 tests passing, with 42 failed and 40 skipped tests. Six
deterministic baseline failures and three governed timing failures matched the
allowlist. Beyond that baseline, 33 test failures and six failed real-sample
suites were caused by unavailable corpus 1.2 fixtures. The complete log is
45,824 bytes with SHA-256
`2efa6d873000557a13f4596a72f649c22e5ac41160a35c71aa1a272e80898716`.

Because the clean checkout cannot evaluate the complete corpus 1.2 population,
its mapping precision, held-out recall, domain activation, action execution,
false-action and explanation gates cannot be re-claimed from this candidate.
The exact corpus 1.3 arithmetic remains valid but cannot substitute for the
missing acceptance corpus.
